# سایت کافه آوین
- تغییر قیمت: فایل menu.json را باز کن و عدد کنار "p" را عوض کن (واحد: هزار تومان). "p":null یعنی قیمت نمایش داده نمی‌شود و عبارت «بپرسید» می‌آید.
- تست روی کامپیوتر: داخل پوشه بنویس `python3 -m http.server` و آدرس localhost:8000 را باز کن (باز کردن مستقیم فایل، منو را نشان نمی‌دهد).
